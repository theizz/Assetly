# Assetly

Steps to run the prototype

1. Install Node.js if you haven't
2. Extract and upload the folder in VS Code
3. Install the extension SQLite Viewer to view the database directly in the IDE 
4. Open the terminal and type -> npm.cmd install express better-sqlite3 bcryptjs jsonwebtoken multer <- to install the packages
5. Type npm start to run the program
6. Wait for this line: Assetly running at http://localhost:3000 (if this shows up, it means you can open the website now)
7. Open a browser and go to http://localhost:3000
8. Log in as admin with admin@assetly.edu / admin123. For the teacher side, louizdizon@gmail.com / louiz1234

- To stop the server, click the terminal and press Ctrl + C
- To reset all data, stop the server, delete assetly.db and the uploads folder, then start again
